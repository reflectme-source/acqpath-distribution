# Stan przekazania 1.0.0

Pakiet przygotowany i sprawdzony lokalnie. 66/66 testów przechodzi na Linux Node22.16.0. Zgodność typów sprawdzona TypeScript5.8.3; 6 stron w 2 szerokościach wyrenderowano lokalnie w Chromium. To nie jest dowód wykonania zewnętrznych publikacji ani płatności.

Nie uruchomiono kont/Cloudflare DNS/Registry/npm/Smithery publikacji, mainnet purchase, e2e portfela Rabby ani rzeczywistego runnera Windows. Przygotowane workflow Windows zostanie faktycznie wykonane dopiero na nowym repo właściciela. Nie ma nowych testów oryginalnego backendu.

Publiczne próby sieciowe w środowisku budowy nie rozwiązywały DNS (EAI_AGAIN), dlatego widoczność i produkcja pozostają UNVERIFIED w tej paczce do lokalnego odczytu u właściciela. Przeglądarka blokowała lokalną nawigację HTTP polityką środowiska; kontrola HTML użyła renderowania in-memory, nie omijania polityki.

Brak Bazaar extension w przejrzanej ścieżce core nie jest rozwiązany samymi docs/server.json. Nie obiecujemy indeksacji pod ograniczeniem „core bez zmian”. MCP obsługuje quote, paid redeem jest HTTP. Operator wcześniej zgłosił DEGRADED reconciliation; nie jest naprawiane.

Skany sekretów obejmują wybrane wzorce i allowlist tarballa, nie pełną certyfikację bezpieczeństwa. Nie ma gwarancji popytu, liczby klientów, revenue, moderacji albo terminu przyjęcia katalogowego. Wiarygodność tych statusów jest ważniejsza od słowa FINAL w nazwie pliku.
